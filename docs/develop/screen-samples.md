# M3 画面素材留档

咖啡和活跃度奖励目前缺少真实奖励后态。本批增加桌面“画面素材”页，供用户手动操作游戏到所需状态后，按需截取一帧、检查预览并保存本机 PNG 与元信息。采集复用已有引擎截图入口，不发送游戏按键或点击。完整领取仍按各应用的素材与验收要求推进。

## 使用与数据

先在总览连接 1920×1080 游戏窗口并选择截图方式，再进入“画面素材”。点击“采集当前画面”，核对截图、采集时间和截图方式，选择画面状态、填写可选备注，然后点击“保存这张预览”。支持活跃度日常页、领取确认、奖励预览，咖啡点单、电量、增益，以及其他画面。状态和备注属于用户标注，不是识别或领取成功证明。DXGI / ScreenDC 仍要求游戏完整可见，具体限制见总览的截图方式说明。

只保留本次桌面会话的最新一张预览；切页后仍可查看，断线后仍可保存已经采集的图片。新采集替换旧预览，重启后清空。保存只使用宿主缓存的采集标识，前端不能提交图片或输出路径；保存期间换页不丢结果。相同标识和相同标注重复保存返回原结果，已保存图片不能更换标注，需要重新采集。

已落盘的图片可在同页的[已保存素材列表](screen-sample-library.md)按状态和备注查找、分页及回看，重启后仍可读取。历史回看独立于本次采集预览，查看历史不会改变“保存这张预览”的对象。

文件写入固定数据目录 `diagnostics/screens/`，每次采集单独目录，包含 `image.png` 和 `metadata.json`。元信息记录采集标识、引擎会话、窗口句柄和进程编号、截图方式、1080p 尺寸、色序、时间、亮度提示、PNG SHA-256、用户状态与备注；不自动附带账号配置、日志、游戏路径或窗口标题。图片先预览，只有用户点击保存才写磁盘，不自动上传或修改测试仓和参考仓素材。

## 实现约定

采集前在同一引擎会话锁中复验目标窗口和截图方式，要求没有运行、暂停或收尾任务、未保存结果、未释放输入、资源切换和结束后倒计时。PNG 受大小、格式、解码尺寸和内存限制；疑似黑帧保留并提示，不能自动认定为失败。

保存使用独立暂存目录，写入两个文件并同步后再改为正式目录；失败清理本次暂存文件，已有目录不覆盖。拒绝目录联接和符号链接。桌面正常退出等待当前写入完成，随后清空缓存，使排队保存的旧标识失效。截图不进入普通日志和配置备份。该功能只增加桌面命令与共享展示类型，引擎协议仍为 v28，执行资源不变。

后续将用户确认的真实素材按各应用画面说明纳入独立测试仓，再验证 OCR、领取分支和顺序交接。保存素材本身不代表画面资料已完成审核或实机执行通过。

## 验证

新增 13 项 Rust 回归覆盖真实日常留档的 PNG 像素往返、固定目录及元信息范围、人工标注、黑帧保留、内存预览、同标识重复保存、旧标识失效、已有目录保护、写入错误后的重试、目录联接拒绝、图片格式和大小、真实解码尺寸、运行与输入释放预检，以及真实桌面管道下的未连接采集拒绝。退出专项确认当前保存完整结束、图片与元信息均存在，再清空预览并拒绝旧标识。连同原日志导出的 6 项，共 19 项 Rust 回归通过。

新增 7 项界面回归覆盖显式采集和保存、只提交标识与标注、切页时采集互斥及保存结果保留、断线保存、失败重试、重采集撤销旧预览、运行与记录拦截、图片解码失败和备注限制。连同外观和原生诊断，共 28 项界面回归通过；明暗主题和 960 像素布局已检查。
