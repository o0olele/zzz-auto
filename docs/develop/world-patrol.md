# 锄大地迁移

目标是迁移旧版应用设置和已有路线，复用 Rust 战斗、导航、账号配置、运行槽和输入恢复。路线录制和大地图录制不属于本次范围。

路线数据包含区域、传送点、地图图标及移动点，按旧版区域与文件顺序加载。白名单和黑名单只过滤路线，不改变路线顺序；未知名单或路线应报错，不能默默执行全部路线。每日循环按区服游戏日累计，轮间隔从本轮开始计算，等待前离开勘域。暂停和停止必须释放移动与战斗输入，恢复后重新截图定位。

执行前冻结配置、路线与战斗脚本。3D 地图传送必须核对点位名称，移动使用小地图图标定位及朝向反馈；失去可靠位置或过期截图时停止移动。有界重试不能增加完成数。路线全部到达且返回大世界、输入释放后才可证明完成。实机验收与离线测试分开记录。

## 使用

在“账号与应用组 → 锄大地”保存路线名单、战斗脚本、每天循环次数、轮次起点间隔、重试和超时。默认运行全部路线，可选择职工社区旧址、科研院旧址、中央制造区或粗加工中心；展开名单可查看起点和行走点数。跑图固定使用前台键鼠，战斗采用当前账号的输入方式和识别设置。游戏须为固定 1920×1080，传送点须已解锁，当前队伍须能应对所选路线。

在独立应用选择“锄大地”，或在应用组中启用后预览并运行。F9 暂停 / 继续、F10 停止沿用已有机制。继续时重新传送当前未完成路线并定位，已完成路线和完整轮数保留。重试耗尽会继续检查其余路线，最后将该轮报告为失败；再次运行从首条失败路线继续。界面消失会停止任务。

轮间等待前传送到录像店房间，间隔从本轮开始计算并扣除跑图耗时。暂停期间不计入活动时间和间隔，跨游戏日会停止并要求重新预览。历史只复用同账号、同应用组、同游戏日且设置相同的新版检查点；完成目标后不重复运行。组运行的“仅本次重新运行已完成应用”可重新开始。修改设置会建立新的运行基线，旧 Python 轮数不作为新版成功证明。

旧账号导入支持按组的 `world_patrol.yml` 和账号目录下的旧格式。路线名单使用随附数据，未知自定义名单会报错。旧版 `silent_fail` 策略可导入；自动重开、登录及 `restart_and_skip` / `restart_and_retry` 尚无新版依赖，导入时明确拦截，不会悄悄转换策略。

## 资源与验证

协议为 v46，桌面和引擎须一起构建。`prepare-engine.mjs` 自动生成独立 schema 1 锄大地资源，开发、NSIS、便携包及运行资源 ZIP 均包含该资源。地图、模板、路线、OCR、Pipeline 和文件数量都校验固定来源及哈希，模板即使连同清单一起被修改也不能载入。旧日常和战斗资源定义保持不变。

```powershell
cargo run --locked -p od-tools -- world-patrol-bundle --reference E:\code\ZenlessZoneZero-OneDragon
cargo run --locked -p zzz-engine -- world-patrol-bundle-check
cargo test --manifest-path zzz-od-test/test/zzz_auto/rust/Cargo.toml --target-dir target/validation --locked --test world_patrol -- --test-threads=1
```

`resources/world-patrol/catalog.json` 保存 6 个区域、21 条路线、4 份名单及定位图标。`source-lock.json` 固定旧仓来源，`image-lock.json` 固定转换后的模板。维护者更新来源时可显式执行 `od-tools world-patrol-catalog --reference <旧仓目录>`，审查差异后重新编译并生成包；普通启动不会重写内置数据。

离线测试涵盖真实路线解析、名单过滤、非法配置、完整轮次计数、间隔扣除、历史隔离、失败续跑、运行槽完成证明、暂停恢复、停止、图标定位歧义、道路匹配和资源篡改。留档 `screens/3D地图/默认.webp` 实际展示地图总览，用于验证返回录像店入口及避免误分类；不能证明真实 3D 地图流程通过。

尚需游戏内验收：任务取消追踪、区域列表与子区域选择、筛选和传送点搜索、实际落点、道路和图标定位、连续行走与转向、卡住脱困、落地战斗、键鼠和手柄交接、录像店返回、长时间循环及断线恢复。保持 `accepted=false`，不变更应用的正式可用标记。

## 传送点详情导致连续上滑的修复

用户测试停在 `[空洞]中央制造区 / 大楼东侧` 的“物流通道”详情页。原执行器只用“快捷导航”和返回按钮判断 3D 地图，未区分右侧区域列表与传送点详情，找不到目标区域后会反复在详情面板内向上拖动。

现在优先匹配详情右上返回箭头并关闭面板，重新截图后再选择区域。详情仍在、关闭按钮不可见、筛选面板未关闭或没有列表证据时不拖动。顶部标题已经是目标区域时直接继续子区域选择。区域选择最多发送 20 次输入，失败后按既有流程释放输入并结束；每次实际拖动也验证鼠标释放。

新增的真实截图、关闭按钮缺失负例、当前区域标题、无列表、输入上限与取消，以及拖动松键回放位于独立测试仓 `test/zzz_auto/rust/tests/world_patrol.rs`。用户原图以 1852×1044 原样留档，离线控制器中统一到 1080p，仅用于复现识别，不构成实机通过证明。

本修复增加了详情返回按钮模板，需重新生成 `world-patrol-bundle` 并重新构建引擎；只启动旧可执行文件不会加载修复。开发入口 `npm --prefix apps/desktop run tauri dev` 会自动完成生成和构建，先退出仍在运行的旧开发程序。

修复后 24 项锄大地回归、Workspace 严格 Clippy、格式检查及引擎构建通过；真实游戏内关闭详情后的连续传送流程仍需复测。

## 筛选面板标题带图标时卡住的修复

第二次实测停在“标识点筛选”。只读检查运行记录确认阶段为 `Filter`；SDK 日志把漏斗图标与标题合并读为 `▼标识点筛选`，原来的纯标题精确匹配未通过。用户剪贴板截图归一化后可能将图标与标题分开，回归同时覆盖这两种 OCR 结果。

标题现在只忽略符号和空白，仍完整校验中文名称。筛选打开、选项投递和关闭由同一个执行入口处理：识别已打开的面板后选择“裂隙信标”或“传送”；用模板定位右上 X，重新读到面板消失、地图恢复后才允许缩放和寻点。即使过渡帧同时出现地图锚点，也优先关闭筛选。打开和关闭每个阶段最多发送三次点击，暂停、停止或找不到关闭按钮时不会继续拖动地图。

本次增加 `menu/btn_close` 模板与筛选实拍留档，需重新生成锄大地资源并重新构建引擎；协议仍为 v46。新增回归覆盖实际日志中的图标前缀、打开→选项→关闭交接、关闭后回读、关闭按钮缺失、取消和点击次数上限。

本次 29 项锄大地离线测试、Workspace 严格 Clippy、格式检查、引擎构建及资源校验通过；未操作真实游戏，关闭筛选后的连续跑图仍需实机复测。

## 传送后只脱困、没有沿路线移动的修复

用户提供了传送落地后的完整小地图截图。隔离控制器回放确认能检测玩家与小地图，但旧道路定位返回空值；执行器因此只会等待、尝试左右脱困，再按重试策略换路线。

道路定位补回原版的玩家掩码、圆形和地图按钮遮罩、先闭后开的形态学处理，并将交并比评分恢复为归一化相关性。该实拍图的交并比约 0.18，无法通过原先 0.45 门槛；相关性约 0.35，可以恢复传送点附近的位置。保留最少道路像素、方差、搜索半径和相隔超过 15 像素候选的分离检查，重复道路不强行定位。地图按钮搜索范围也覆盖截图中的下移位置，动态裁剪无需拉伸带标题栏的图片。

移动输入提取为执行器和回放共用的入口。新鲜的位置与朝向才能触发转向及 150 毫秒 W 输入，结束后松键；取消、过期、遮挡、位置或朝向缺失均不移动。原始 PNG 及来源说明保存在独立测试仓的 `test/zzz_auto/fixtures/world-patrol-overworld-20261025.*`。等像素平移和遮挡负例只在内存生成，未修改原图。

实拍回放已能定位到首条路线起点附近、读出向上的朝向，并转向和前进至首个路点方向。完整路线行走与遇敌战斗仍未实机验收。本次只改变 Rust 实现，现有资源可继续使用；需要重新构建并重启引擎，旧进程不会自动获得修复。

本次 34 项锄大地离线测试通过，随后补充的非法起点边界检查与道路定位三项回归也通过。Workspace 全目标严格 Clippy、格式与差异检查、引擎构建及锄大地资源校验通过。

## 搜索信标时旧详情导致连续上滑的修复

新实拍右侧打开“大楼东侧”详情，只读运行记录确认停在 `Search`、目标为首条路线“中央制造区入口”。此前修复只覆盖 `Area` 阶段。`Search` 仍会反复读取残留详情里的参考点名称，计算同一方向并拖动，而没有重新侦察当前视口。原图上方信标的匹配框顶边为 73，还被旧搜索框上边界 85 截断。

现在搜索由执行器和离线控制器共用一个有状态入口。先关闭进入搜索前残留的非目标详情，再逐个检查同帧识别出的可见信标；非目标详情必须关闭并重新读到地图后才继续。检查完当前视口后，使用本轮点击确认的参考点平移一次并清除参考，重新侦察；无参考时采用不同方向探索。搜索框上移至 65，使该实拍中的两个信标均能匹配。

搜索最多平移八轮、投递 96 次输入；详情持续不关闭最多点击三次后明确失败。详情存在却没有关闭按钮时等待，取消和过期截图不发送输入，已选中目标时直接进入确认。暂停后仍从既有检查流程重新开始，不持久化半途的搜索参考点。

新原图及来源说明位于独立测试仓 `test/zzz_auto/fixtures/world-patrol-east-side-detail-20261025.*`。回放覆盖残留详情、逐个可见信标、参考点只用一次、目标已选中、关闭按钮缺失、取消、过期与搜索上限；合成过渡帧只用于验证交接，未操作真实游戏。本次不改变协议或资源，重启时仍需重新构建引擎。

本次 40 项锄大地离线回归、Workspace 全目标严格 Clippy、格式与差异检查、引擎构建和资源校验通过；完整连续传送与跑图仍需实机复测。
