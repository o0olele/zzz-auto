# M3 全局任务快捷键

本批补充通用设置中的暂停 / 继续与停止。默认 F9 暂停或继续已有任务，F10 停止。没有任务时不启动应用，启动继续使用现有预览及输入确认。邮件、地图和咖啡沿用引擎的暂停检查点与输入释放；输入探针等只有停止能力。

快捷键由桌面 Rust 进程在专用 Windows 消息线程注册，最小化或隐藏到托盘仍然有效。原生消息转换为携带运行 ID 的现有引擎命令，不通过前端定时器处理。按 [Windows RegisterHotKey 约定](https://learn.microsoft.com/zh-cn/windows/win32/api/winuser/nf-winuser-registerhotkey)使用 MOD_NOREPEAT，长按不重复触发；暂停中和停止中不切换状态，旧运行的消息不能控制后来开始的任务。控制队列有容量限制，等待超过 2 秒的请求丢弃并提示重新按键。

设置保存于 `general.shortcuts`，可分别选择 F1 至 F11 或关闭，不允许两个动作使用同一个键。旧配置缺少此对象时兼容默认值；对象存在时严格校验，显式 null 表示关闭，缺少字段、未知键或未知字段均报错。旧版 `env.yml` 中 `key_start_running` 与 `key_stop_running` 的 F1 至 F11 可转换，大小写兼容；不支持的按键保留原文并提示采用默认值，旧“开始 / 暂停”键只保留暂停 / 继续含义。转换预览指纹升级至 v4，旧预览须重新生成；CLI 在创建目标目录之前拒绝已过期的预览，取得目录锁后仍重新扫描及核对。

保存设置和系统注册分开报告。注册遇到占用等错误时撤销本组全部注册，界面显示“未生效”及原因，不继续使用旧按键；可修改设置或在空闲时重试。引擎断线时清除运行目标，快捷键不会重连或启动游戏操作。注册状态与控制错误通过独立桌面状态发送，控制失败不伪装成引擎断线。退出桌面时注销快捷键。

## 验证与试用

独立测试仓新增 5 项 Rust 快捷键用例，验证旧配置只读兼容、严格校验、保存与冲突、导入归档及敏感原值隔离、运行状态和运行 ID 约束，以及 Windows 原生注册冲突、部分失败撤销、改键释放和关闭注销。原生注册测试不发送真实按键。账号配置 15 项、应用组 8 项及每日计划 7 项回归通过。另 1 项资源包专项检查 schema 1 / 协议 15..18 与 schema 2 / 协议 16..18，拒绝 schema 2 / 协议 15 及未知版本，合计 36 项针对性 Rust 用例通过。

界面新增 3 项用例，连同既有账号 / 设置用例共 15 项通过：保存、禁用、重复键、切页读取、注册失败、重试、控制失败不误报断线，以及运行和断线拦截。明暗主题截图已检查。沙箱内首轮浏览器测试收尾挂起，中止后在普通权限重跑，15 项完整结束。workspace 与相关独立测试的严格 Clippy、前端生产构建通过。协议为 v18，桌面与引擎需成套更新；未重打包便携 ZIP。

重启更新后的桌面，打开“通用设置”，核对“当前注册”显示 F9 / F10；若提示占用，可改键保存或重试。在已有邮件试运行的启动延时或识别等待阶段，切回游戏后按 F9，等待任务确认为暂停，再按 F9 继续；另一次运行可按 F10 停止。没有任务时按键不会启动应用。真实游戏前台、托盘隐藏及管理员引擎场景仍待实机验收，不据自动注册或模拟界面测试登记通过。
