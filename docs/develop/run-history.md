# M3 运行记录筛选与导出

桌面增加独立的“运行记录”页，读取所选账号已保存的应用组记录，按应用、组标识、游戏日和结果筛选。账号与应用组页的最近记录入口继续保留。查询和导出不改变每日完成判断，也不启动游戏操作。

## 查询约定

引擎按开始时间、运行 ID 降序，每页最多返回 20 条，并限制单页序列化大小。后续页使用最后一条记录的时间和 ID 作为游标，期间新增的较新运行不会把上一页记录挤入下一页。刷新回到第一页；切换账号或筛选条件会清空旧页和游标。筛选按记录中冻结的组标识及游戏日执行，组重命名后仍可查历史。

结果区分正常完成、失败、超时、主动停止、运行中与异常中断。“运行中”筛选包含暂停和收尾中的存活任务。异常中断表示磁盘记录没有终态且不是当前存活任务，不推断实际结束时间。应用筛选检查冻结计划中的应用，整组失败仍会保留前项成功的分项状态。坏文件计数，目录读取失败直接报错；未知版本、账号不匹配及过大文件继续拒绝读取。

## 导出约定

“导出本页记录”将当前筛选和本页已保存内容导出为 JSON，包含分项、业务证明、输入释放状态、运行 ID 和时间，不包含截图、账号凭据或其他账号记录。导出前重读并复验页面内容指纹；内容变化须刷新后重试，防止可见结果与导出不同。

输出固定在引擎数据目录的 `runs/exports/`，文件采用随机名称且不覆盖已有文件，不接受客户端路径。写入失败删除本次不完整文件。导出仅代表本页，不是全部历史或配置备份；未保存结果不会被当作已保存结果导出。断线、切页或账号变化后的迟到响应不更新当前页面。

协议升级为 v25；旧运行资源继续兼容：基础包 schema 1 / 协议 15..24、咖啡包 schema 2 / 协议 16..24，当前 v25 包继续按对应 schema 校验。
