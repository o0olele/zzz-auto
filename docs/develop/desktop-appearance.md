# M3 桌面外观设置

本批补充通用设置中的界面偏好：跟随系统、浅色、深色主题，以及 90%、100%、110%、125% 界面缩放。外观与自动化运行参数分开保存，任务运行、引擎断线和浏览器预览时均可调整。

## 保存与生效

在“通用设置 → 桌面外观”选择主题或缩放，更改后立即应用并保存。默认跟随系统、100% 缩放；跟随系统时，系统明暗变化自动更新界面。侧栏的明暗按钮保留，点击后改为对应的固定主题；可在设置中重新选择跟随系统。“恢复外观默认值”恢复并保存上述默认值。

偏好保存在当前 WebView / 浏览器源的本地存储 `desktop-appearance`，包含版本、主题选择和缩放比例。已有 `theme=light/dark` 偏好在没有新格式时继续读取；首次读取不写盘，也不会把“跟随系统”保存成某个固定主题。缩放仅改变界面，游戏截图、1080p 坐标和输入参数不变。账号导入、备份及恢复不包含界面偏好，便携数据目录也不负责携带这些偏好。

损坏或未知版本的偏好使用默认外观并显示说明，保留原文，直到用户明确修改或重试保存。存储不可用时仍应用本次选择，并提示无法跨重启保存；存储错误不能使整个界面退出。恢复存储后可以重试保存当前外观。

## 验证与范围

本批不修改引擎协议、账号 schema 或运行资源包。系统缩放继续由 Windows / WebView2 处理，界面缩放在此基础上生效；浏览器验证不能代替真实 WebView2 和 Windows DPI 的实机验收。

独立测试仓新增 9 项界面用例通过，覆盖系统主题变化、固定主题及刷新读取、旧偏好兼容、侧栏切换与恢复默认、损坏 / 未知 / 类型错误 / 越界 / 多余字段、存储失败和恢复后的重试、真实控件缩放、键盘操作及最小 960 × 640 窗口导航。连同相邻账号、设置、应用组、地图、邮件、输入和截图共 51 项回归通过；生产前端及含静态资源的原生 debug 桌面构建通过，保留已有单块大于 500KB 提示。明暗主题和 960 像素宽截图已检查。首轮缩放检查发现侧栏底部被导航挤出，已将导航区改为独立滚动并按缩放后的可用尺寸调整布局。
