# M3 通用运行设置

本批迁移默认截图方式及邮件运行参数，接通 Rust 保存、桌面表单、应用组预览和实际执行。区服与每日完成策略已接通[应用组每日计划](daily-runs.md)。多应用实际执行、咖啡等新日常及资源下载继续按路线图推进。

## 配置与表单

设置位于宿主数据目录的 `config/accounts.yml` 中的 `general` 对象，所有账号共用。与账号和应用组共用修订号、文件锁、保存前备份及临时文件完整替换；任何配置修改都会使旧应用组预览的修订失效。运行、暂停、停止收尾及原生请求未结束时，引擎拒绝保存。损坏设置和未知字段报错，不静默恢复默认值。

| 字段 | 默认值 | 允许值与作用 |
| --- | --- | --- |
| `capture_method` | `frame_pool` | FramePool、PrintWindow、DXGI、ScreenDC、GDI；桌面下次连接 / 获取截图的默认方式 |
| `mail.timeout_ms` | `60000` | 1..60000 的整数；有效运行超时，暂停时间不计入 |
| `mail.start_delay_ms` | `3000` | 0..10000 的整数；启动和继续前留给用户切回游戏的时间 |

已有 v1 账号配置缺少整个 `general` 对象时，新引擎只读补入默认值，不因读取而写盘；保存时连同账号配置写入。对象存在但缺字段、参数越界、枚举未知或包含未知字段时拒绝加载。回退旧原型需要使用保存前备份，旧原型不认识新增的设置对象。

普通表单的字段名、标签、截图选项及整数范围由 Rust 的 `GeneralSettings::fields()` 定义，通过 `od-tools types` 与协议一起生成到 TypeScript，桌面按定义渲染并校验。数值上限与引擎 `MailConfig` 校验共用常量。后续已接入[全局暂停 / 继续与停止快捷键](global-shortcuts.md)，选项同样由 Rust 生成；旧设置缺少整个 `shortcuts` 对象时补默认值，对象存在时必须显式给出两个按键或 null。主题继续属于界面偏好，通知、游戏启动参数及战斗设置尚未迁移。

## 使用与生效

桌面侧栏打开“通用设置”，修改后点击“保存通用设置”。读取失败保留错误并禁用保存；冲突时重新读取最新设置，核对后重新编辑，不自动重试覆盖。保存失败不显示成功；断线或离开页面后到达的旧响应不能恢复表单或显示保存成功。

截图默认值在桌面连接引擎后读取，不再从浏览器 `capture-method` 缓存读取或保存。保存设置不会立即重建已连接的控制器：回到总览重新连接窗口，或在原生诊断点击“获取截图”，再应用新方式。原生诊断和总览中的截图下拉框仍可临时选择，只影响本次连接；要跨重启保留请使用通用设置。CLI 的显式截图参数保持原行为。

应用组预览显示实际使用的启动 / 继续延时与超时。开始请求只携带账号、组和配置修订以及输入确认；引擎重新读盘、核对修订后冻结邮件参数，写入运行记录并执行。客户端不能通过应用组请求替换这些参数。暂停和继续沿用该运行已冻结的参数。

邮件诊断表单从保存值初始化，仍允许为本次诊断临时调整，不回写通用设置。应用组只开放已有邮件试运行，其他应用的可执行范围不变。

## 旧配置导入

`od-tools import-config` 继续先预览、核对指纹后导入。增加检查旧 `config/env.yml` 中的 `screenshot_method`：显式 `print_window` 转为 PrintWindow；自动选择、BitBlt、PIL、未知值或缺省值保留原文，预览提示采用 FramePool 后需手动核对，不假定具有相同行为或自动回退。环境文件内其余字段仅归档，不通过协议返回。邮件参数采用新版本默认值。

预览指纹包含转换版本，最新版本及区服导入见[每日计划](daily-runs.md)；转换规则变化后旧预览须重新生成。此前已导入的数据不会被重新覆盖，需要在桌面编辑设置；仍只允许向空白配置首次导入。首次导入前不要保存默认账号或通用设置，否则会建立正式配置并拒绝覆盖。

## 验证

独立测试仓覆盖旧 v1 读取、严格校验、无效设置不写盘、重读持久值、修订冲突、账号保留、旧截图方式转换及原文归档、重复导入保留编辑。邮件与输入恢复回归验证引擎使用保存参数、暂停禁止改配置，以及应用组移除客户端参数后仍在发送前登记完整输入恢复计划。界面回归覆盖表单、保存失败、冲突、断线、临时诊断参数、应用组预览及明暗主题布局。

```powershell
node scripts/prepare-engine.mjs
cargo test --manifest-path zzz-od-test/test/zzz_auto/rust/Cargo.toml --target-dir target/validation --locked --test account_config --test group_runs --test mail_pipeline --test input_recovery --test regression --test elevation -- --test-threads=1
npm --prefix apps/desktop run build
npm --prefix zzz-od-test/test/zzz_auto/frontend test -- --reporter=line
```

协议为 v12，需成套使用桌面、引擎和生成类型。验证使用临时配置、固定画面、模拟控制器与隔离窗口，未修改用户旧配置或操作真实游戏；真实数据导入及不同截图方式的游戏表现仍保留实机验收。本轮未重打包便携测试 ZIP。
