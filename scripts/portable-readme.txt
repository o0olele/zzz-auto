绝区零一条龙 · Rust 原型 0.1.4（Windows x64）

使用方法
1. 将整个压缩包解压到可写目录，保持全部文件和子目录完整。
2. 双击 zzz-desktop.exe 或 launch.cmd。无需安装 Python、Node.js 或 Rust。
3. 若电脑缺少 WebView2，运行 tools\MicrosoftEdgeWebview2Setup.exe；该微软安装器需要联网。安装完成后重新打开应用。
4. 打开绝区零，设置游戏客户区为 1920×1080，在控制台点击“扫描窗口”与“连接窗口”。
5. 在“原生诊断”获取截图、运行健康检查并测试停止。
6. 在“真实输入诊断”选择前台 / 后台键鼠或 Xbox / DS4，再选择按键、摇杆或扳机动作，填写对应参数和时间，勾选允许这次真实输入后启动。默认延时三秒、按住半秒；鼠标被游戏锁定时可先按 Win 或 Alt+Tab 返回工具，启动后在延时期间切回游戏。停止后等待输入释放终态。可观察游戏是否响应、是否还有残留动作。
7. 邮件试运行位于“原生诊断 → 邮件流程试运行”，从大世界、菜单或邮件列表开始。确认本次领奖后启动，在准备延时内切回游戏并保持前台。暂停先等待释放确认，继续保留本次领取进度；停止后等待终态，异常退出后先完成“恢复遗留输入”再手动重连，不会自动续跑。
8. 地图试运行位于“原生诊断 → 地图传送试运行”，固定传送至“澄辉坪 → 汀曼咖啡”。先在游戏按 N 打开普通地图，然后回到工具确认本次路线并启动，在延时期间切回游戏。目标须已解锁且可见；暂停保留检查点，继续不重放已尝试的传送。完成后核对落地位置，咖啡点单需使用下面的独立入口，每日记录尚未接入。
9. “一条龙运行”与“独立应用运行”可试运行邮件、咖啡、活跃度奖励、丽都城募与刮刮卡。先选择当前账号和应用组，预览并确认计划与输入后启动；各项游戏串联及边界继续待验收。原生诊断仍保留独立咖啡点单入口。
10. “自动战斗”提供自动战斗与闪避助手，先保存账号对应的脚本、输入与识别设置，进入战斗画面后确认启动。支持预览并导入旧项目脚本快照；F9 暂停 / 继续，F10 停止。继续会重新识别，不重放暂停前动作。声音默认关闭，启用后回录系统输出音频；键鼠、Xbox / DS4、转向及声音阈值均保留实机验收。

当前范围
M0 已完成，M1 待验证，M2 邮件主流程通过、边界待验收，M3 / M4 开发完成、待验收。可测试账号与应用组、配置导入与恢复、设置与资源管理、SDK、截图、通信、首批日常、自动战斗和输入诊断；应用正式可用标记继续关闭。
本包附带邮件、地图、咖啡、日常 schema 10、战斗及迷失之地场景资源，包含 Pipeline、PP-OCRv5、固定闪光和导航 YOLO 模型。迷失之地导航复用日常包内的固定模型；独立应用和应用组已提供试运行入口，普通保持当前队伍人数、少人出战确认和入口更新弹窗仍在开发，全部实际游戏验收保留。第三方插件和其他复杂应用按后续阶段迁移。
桌面默认使用 FramePool、CPU 和前台控制器。邮件只支持前台键鼠；手柄诊断另需 ViGEmBus 驱动，本包不安装驱动。
如果截图是黑色，在原生诊断选择 PrintWindow 后重新获取截图；也可尝试 DXGI / ScreenDC，但游戏必须完整可见，未最小化且未被其他窗口遮挡。选择方式后点击获取截图会自动重连控制器。
截图含疑似黑帧提示和亮度统计。加载过场可能是真实黑屏，请进入有正常画面的游戏场景再测试。截图方式偏好会保存，引擎日志记录实际使用方式及统计。
输入诊断支持数字按键、鼠标按键、Xbox / DS4 左右摇杆和左右扳机。前台诊断要求延时结束时游戏处于前台；若提示游戏权限高于引擎，先停止任务，再在总览中点击“提升引擎权限”，授权成功后手动重连游戏。键名下拉包含 W、空格、Esc、Shift、数字、F1–F12 等。鼠标坐标为游戏客户区 X 0..1919、Y 0..1079，前台方式会移动光标；摇杆 X / Y 为 -32768..32767，X 正值向右、Y 正值向上；扳机力度为 1..255。持有最长两秒，停止后等待鼠标释放、摇杆回中或扳机归零。
用户已反馈前台键盘持有期间停止与无残留动作，以及实际后台 Xbox 数字按键正常；两种后台键盘均未生效，暂保留供诊断。0.1.4 鼠标按键及 Xbox / DS4 摇杆与扳机已有基础实机通过反馈；具体前后台组合、DS4 数字按键、完整任务与异常收尾继续验收，具体范围见 ACCEPTANCE.md。桌面与引擎使用同一套 0.1.4 / v34 协议文件。

数据与退出
portable.flag 表示便携模式，数据和运行日志保存在当前文件夹的 data\，不依赖源码目录或启动时的工作目录。
关闭主窗口会隐藏到托盘；点击托盘“停止并退出”结束引擎。
移动整个文件夹即可移动程序与数据。不要从压缩包内直接运行 exe。

排查问题
双击 check-environment.cmd 可检查 Maa 原生 SDK、邮件、地图、咖啡、首批日常和战斗资源完整性，结果保存为 diagnostic.log。
若提示邮件资源缺失，请重新完整解压本包；不要只复制 exe。资源补丁 ZIP 可直接解压到 zzz-desktop.exe 所在目录，解压后应存在 resources\generated\mail\mail-manifest.json 及其全部子目录。测试机无需运行 od-tools 或安装 Rust。
报告问题时可附上错误文字及 diagnostic.log；引擎日志位于 data\maa-log\。
release-manifest.json 记录运行文件的 SHA-256、SDK 和运行库版本。
