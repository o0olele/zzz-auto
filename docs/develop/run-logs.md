# M3 运行日志查看与导出

独立“运行日志”页补充按引擎会话、运行 ID、级别及文字筛选，分页查看和暂停画面刷新。暂停日志刷新不暂停游戏任务。离开页面后不继续请求日志，重新进入读取宿主保存的快照。

桌面宿主从现有引擎快照收集日志，每次启动的引擎分配不同会话 ID，避免重连、提权或资源切换后重复的事件序号混在一起。最多保留最近四个会话，各保留引擎最近 256 条事件；单条文字超过 8 KiB 时按 UTF-8 边界截断并计数。引擎断线保留最后收到的日志，重启桌面不恢复内存快照。丢弃、截断与会话淘汰数量单独显示，不把这些日志称为完整运行历史。

导出取所选会话在请求时的最新快照，不受页面筛选影响，写入当前桌面数据目录的 `logs/exports/`。内容只有会话标识、采集时间、事件、丢弃 / 截断计数及最近运行概要，不读取账号配置、旧 YAML、截图或 Maa 原始日志。前端不能指定导出路径或提交任意日志内容。文件在工作线程写入，错误明确返回，不阻塞引擎控制。读日志与导出均限定本地主窗口，不要求引擎在线，不新增引擎协议。

本批不自动记录完整历史，不删除已有导出文件。日志 JSON 使用 `schema_version: 1` 和 `scope: retained_engine_events`，文件名带随机编号，重复导出创建新文件。文字按原始文本显示，不作为 HTML 执行。分页每次最多渲染 50 条，筛选无结果时明确显示空状态。

## 使用

重启更新后的桌面，侧栏打开“运行日志”。默认查看最近引擎会话；可以选择旧会话、级别、运行 ID 或搜索文字。点击“暂停日志刷新”固定当前画面，手动“刷新日志”仍可取得最新快照。重连产生新引擎时，旧会话继续保留在列表内，直到超过四个会话被淘汰。

点击“导出会话日志”后，页面显示实际条数、会话 ID 和可复制的文件路径。导出包含该会话请求时最新收到的全部保留事件，不受筛选或画面暂停影响。引擎已经断线时仍可导出。目录不可写、路径含目录联接或会话已淘汰时明确报错，不显示成功。切页后到达的旧响应不恢复成功提示；导出请求发出后文件工作仍会收尾。

导出目录位于当前桌面数据目录；安装版 / 开发版通常为 `%APPDATA%/io.onedragon.zzz-auto/logs/exports/`，便携版为程序目录下的 `data/logs/exports/`。旧“原生诊断”日志仍保留，不影响既有使用。

## 验证

新增 6 项 Rust 用例覆盖四会话容量、序号重置不混合、事件与 UTF-8 截断、丢弃计数、原始快照不变、导出内容与固定目录、重复导出、已有文件保留、无效及目录不可写失败、目录联接拒绝，以及真实桌面命名管道重启两次引擎后按不同会话导出。连同既有会话 12 项与快捷键 5 项，共 23 项针对性 Rust 回归通过。

新增 6 项界面回归通过，覆盖浏览器预览禁用、会话 / 运行 / 级别 / 文字筛选、50 条分页、暂停与手动刷新、断线后整会话导出、重复提交拦截、读取和保存失败、切页及切换会话后的旧响应、会话淘汰恢复。相邻账号 / 设置 15 项回归通过，共 21 项界面用例；明暗主题及 960 像素宽布局已检查。主 workspace 与相关测试严格 Clippy、生产前端及原生 debug 桌面构建通过。

```powershell
node scripts/prepare-engine.mjs
cargo test --manifest-path zzz-od-test/test/zzz_auto/rust/Cargo.toml --target-dir target/validation --locked --test run_logs --test elevation --test shortcuts -- --test-threads=1
npm --prefix zzz-od-test/test/zzz_auto/frontend test -- run-logs.spec.ts accounts.spec.ts --reporter=line
```

本轮没有操作真实游戏、读取真实账号配置或更改资源选择。日志页来自真实游戏任务的显示和实际用户数据目录导出仍待实机验收；原生测试使用隔离目录，界面测试模拟桌面宿主。协议保持 v18；没有重打包便携 ZIP，M3 保持进行中。
