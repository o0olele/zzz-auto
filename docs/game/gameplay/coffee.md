# 咖啡店

咖啡用于恢复电量，并可能提供增益。参考实现将常规咖啡视为每日一次、04:00 重置；额外咖啡和已喝过提示属于另外的分支，不能仅凭返回大世界认定本次领取成功。

本轮只处理澄辉坪的汀曼咖啡。参考 `CoffeeApp.move_and_interact` 表明该地点的传送落点可以直接按 F 交互，六分街所需的转向和前移不适用于这条固定路线。普通地图使用 N 打开；在传送完成、大世界画面稳定后交互，再等待汀曼大师对话。

选项出现前可能有多句对话。只有识别到汀曼大师标题才推进对话；出现目标咖啡选项后停止推进并交给点单流程。没有目标咖啡、对话退出或已喝过时，本轮不能记录为领取成功。常规流程的成功依据为本次点单、电量出现、确认后返回大世界；画面依据见[咖啡画面](../screens/coffee.md)。

上述进店路径来自旧实现，尚未取得新引擎实机证据；界面变化和实际落点仍需验收。
