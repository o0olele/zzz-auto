# 模拟室代理人方案的详情选关

继续完整体力刷本目标，沿用用户暂不启动游戏、保留实机验收的选择。当前真实素材仅含领奖页，参考画面文档将详情和出战列为待建档；因此仍不能把投递回执当作选中证明。此处补齐模拟室代理人方案在详情内必须经过的目标解析与选择步骤，并与已有代理人导航接通，生产选中证明、消费、计次和正式入口继续开发。

依据参考 CombatSimulation.choose_mission、cv2_utils、实战模拟室区域和固定副本目录：先由本次导航保留具体类型；详情入口先使用自己的返回模板回类型页，再投递该具体类型。进入详情后，在 128,740..1798,776 的顶部区域按参考外轮廓顺序取第一个培养标记，中心向下 80 像素作为点击位置；同帧将它与同一横向列中的唯一完整关卡名称配对，名称须属于冻结类型。只看第一个标记，不借用其他标记或邻列名称。原代理人计划及占位关卡不改写，类型、关卡和像素指纹属于本次选择。

未找到可配对目标时，沿用当前模拟室选择器的十次完整翻页上限，按参考中心减 100 像素为起点向左拖动 400 像素。完成拖动才增加次数；中途暂停先释放，继续后从新帧重读。最终仍需已知本类型列表和无候选读数，才返回未找到，不能增加次数或声称培养已完成。重复、重叠、目录顺序异常、其他类型的完整名称及不支持页面均拒绝投递。

返回、类型、翻页及选择各自保存意图与投递状态。输入前重新读取同帧上下文，未投递选择的标记或名称变化则撤销该意图；已投递后冻结本次目标，不重复选择。投递后新帧须保留该完整名称和有效电量，回执仍为 selection_verified=false。暂停后撤销旧回执，只复读已投递选择的后态；不确定的原生输入结果保留意图并阻止重放。

独立 agent-mission schema 1 资源固定参考来源、原返回模板、PP-OCRv5 和只读节点，原模拟室与导航资源定义保持。父流程在输入前预检并冻结导航和本资源，独占同一原生槽位、控制句柄和活动预算；真实到达后才建立对应具体类型的选择器。结果仅为未找到或等待选中验证，不交给卡片、电量恢复或挑战计次。正式体力执行仍拒绝尚未接通的模拟室代理人计划。
